# Delineo Disease Modeling

Delineo is a research platform for modeling how an infectious disease spreads
through a small community, hour by hour and person by person. It combines
Census and mobility data, a synthetic population, and an airborne-transmission
simulator. The live site is <https://covidmod.isi.jhu.edu>.
