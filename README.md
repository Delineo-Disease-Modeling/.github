# Delineo-Disease-Modeling/.github

This repo holds two things for the
[Delineo-Disease-Modeling](https://github.com/Delineo-Disease-Modeling)
organization:

- `profile/README.md`: the page shown at the top of the org's GitHub page
- `docs/`: the project-wide documentation, public so anyone can read it before
  they're added to the org

Start with [docs/START_HERE.md](docs/START_HERE.md).

Each service's own docs live in its repo:
[Fullstack](https://github.com/Delineo-Disease-Modeling/Fullstack#readme),
[Algorithms](https://github.com/Delineo-Disease-Modeling/Algorithms#readme),
[Simulation](https://github.com/Delineo-Disease-Modeling/Simulation#readme).
Anything about the production server stays in the private Deploy repo.

Docs changes go through a pull request, like code. If your change makes a doc
here wrong, fix it in the same PR set.
